# 已知缺口与边界

这份文档列出项目没有闭合、没有验证或不应被当作结论的部分。写作品集时保留它，比只展示成功画面更可信。

## 源机制

- **头发自投影的结构化光照**：源像素着色器采样角色阴影图，实现头发对脸和身体的投影；当前目标侧未完整实现，千夏下层发丝偏亮。
- **完整源 MRT / Stencil 生产链**：只恢复了必要接收关系，没有恢复源每个 MRT 的生产者和完整 Stencil 布局。
- **源 TAA 与锐化**：没有实现，比较图里可能看到边缘和细节差异。
- **源光照 provider**：环境来源、局部灯记录和部分全局参数仍是目标近似；没有把捕获常量写成通用 provider。
- **完整输出链**：源角色 MRT 到最终输出的部分生产者未闭合，R8 只做线性调色、亮部滤波和覆盖合成。
- **Blend / Depth 完整状态**：眼部独立 Alpha 因子与源不同，目标使用 Alpha over；源有效完整 Blend 状态未闭合。

## 角色与资产

- **腰间电子宠物屏幕**：`Body_Screen` 由后续 Draw 绘制，当前未接入。
- **薇薇安 Body_1 叠加纹理**：`cb3[106].x` 控制的叠加纹理未实现。
- **薇薇安宝石 PS 布局**：沿用旧值，未逐项核对。
- **未绑定候选**：独立 Hair / Gem 候选 Shader 只做编译与静态检查，未做生产像素验收。
- **几何身份**：部分捕获几何、脸 / 眉双来源和运行时 LOD 可见组合仍未唯一闭合。

## 验证条件

- 像素比较是固定机位、固定姿态、固定画质、固定帧的结果，不能外推到任意条件。
- 高分辨率 Play（2048×2048 角色 RT）没有完成最终现场验收；旧 640 截图不替代。
- 没有做 Editor 进程重启后的完整回归。
- 没有性能基准和实际成本测量；不宣称优化收益。
- 视觉验收由人决定；文档中的数值阈值只是统计门槛。

## 范围

- 不还原 UI（千夏）、完整名册、切页演出、战斗特效或完整动画状态机。
- 不处理其他角色、全场景或可执行版本。
- 不包含游戏原始资产、捕获数据、反编译 Shader 或第三方解包工具。

## 表述规则

- “已验证”只用于有受控实验或数值记录的部分。
- “推断”必须给出竞争解释和补证方向。
- 目标画面接近不能写成源算法等价。
- 学习精简版不能宣称完整源实现。
- 两个角色共用框架有源证据（同组 Shader 与相同 LUT），但这不等于所有角色、所有状态通用。
